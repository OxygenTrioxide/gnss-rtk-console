# GNSS RTK 程序设计面试题（参考答案卷）

> 与《面试问题.md》一一对应（Q1~Q15）。★ 题为课件表述与工程实践不一致之处，答案给出本工程的实际做法与代码出处（`gnss/src`、`gnss/include`）。

---

## 第一档：基础原理

**Q1. SPP 观测方程与最小二乘流程**

伪距观测方程（对流层/电离层未校正前）：

P = ρ + c·(dt_r − dt^s) + I + T + ε_P

其中 P 为伪距观测值；ρ = ‖X^s − X_r‖ 为卫星至接收机的几何距离；c 为光速；dt_r、dt^s 分别为接收机钟差、卫星钟差；I、T 分别为电离层、对流层延迟；ε_P 为观测噪声及多路径。

单历元未知数为接收机坐标 (X, Y, Z) 与接收机钟差（每系统一个，如 GPS+BDS 共 2 个钟差），需至少 6 颗卫星。最小二乘流程：① 用 SPP 初值（或上次结果）线性化：∂ρ/∂X_r = −(X^s−X_r)/ρ，构建设计矩阵与常数项 l = P − (ρ0 + c·dt_r0) + 电离层/对流层模型改正；② 最小二乘求解 δx = (AᵀPA)⁻¹AᵀPl，更新参数；③ 迭代至改正数小于阈值（本工程约 1e-4 m）。代码对应 `gnss/src/spp.cpp` 的 `SppPosition()`。

**Q2. 站间单差**

单差：同一卫星、同一历元，两个测站观测值相减，本工程定义为 dP = P_base − P_rover（`rtk_sd.cpp` 的 `BuildSDModel()`）。消去的误差：卫星钟差、卫星轨道误差、卫星端硬件延迟（对同一颗卫星两端相同）。消不掉、只削弱的：大气延迟（电离层、对流层——两端路径不同但空间相关，短基线下大幅削弱）、多路径、观测噪声（差分后噪声叠加不消反增 √2 倍）；接收机钟差不消，作为未知参数保留在方程中。

**Q3. 双差与短/长基线**

星间差：两颗卫星的单差再相减。双差同时消去：接收机钟差、接收机端硬件延迟、卫星钟差与轨道误差。短基线（<10 km）下，两端电离层路径差和大气路径差只有亚米级甚至厘米级，在双差模型中被模糊度与噪声吸收，可忽略，故可直接采用无电离层组合或单频双差；长基线（数十公里以上）两端大气延迟不再相关，残余成为系统误差，必须用无电离层组合消电离层、用模型/参数化吸收对流层（如估计天顶湿延迟），否则模糊度无法收敛。

**Q4. 基准星选取与换星重初始化**

原则：选高度角最高（或信噪比最强、观测最连续）的卫星作参考星——它参与所有双差方程，其观测质量直接放大到整个方程组。也可按本工程做法结合周跳探测结果排除近期跳变的星。换星时所有双差模糊度 N_dd(i) = N_sd(i) − N_sd(ref) 都是相对参考星的，参考星变化意味着全部模糊度参数被重新参数化，浮点值整体平移、整周模糊度集合改变，旧的固定解失去意义，必须丢弃全部模糊度状态重新初始化（本工程 `FixDDAmb()` 在参考星集合变化时直接重置模糊度数组）。

## 第二档：数据格式与工程实现

**Q5. OEM7 帧结构与切分**

OEM7 二进制帧：同步字节 0xAA 0x44 0x12 + 28 字节标准头（报文 ID、报文类型、长度、周/毫秒时间戳、接收机状态、软件版本等）+ 变长数据区 + 4 字节 CRC32。切分用状态机（`gnss/src/oem7_decode.cpp` 的流式解码）：先按字节扫描同步头（为防伪同步，要求 0xAA44 后一字节恰为 0x12），找到后读出头部长度字段确定整帧长度，再从流中收集"头+数据区+CRC"的全部字节，CRC 校验通过才解出报文并派发（RANGE/BESTPOS/RANGEGPSL1 等），失败则逐字节滑动重新找同步头。

**Q6.★ OEM7 CRC32 与标准 CRC32**

NovAtel 定义的 CRC32：多项式 0xEDB88320（与标准 CRC-32 相同），但**初值 init = 0x00000000、无最终异或（xorOut = 0）**；而 zlib 的 `crc32()` 及多数"标准 CRC32"实现是 init = 0xFFFFFFFF、最终再异或 0xFFFFFFFF。两处差别导致校验值完全不同。若直接拿 Python `zlib.crc32(frame)` 去校验 OEM7 帧，**每一帧 CRC 都不匹配，全部被判定为坏帧丢弃**，解码器收不到任何观测。正确做法（本工程 `oem7_decode.cpp` 的 `crc32()`）：移位寄存器初值置 0，按字节查表更新，输出不异或；或用 Python `crcmod.mkCrcFun(0x104C11DB7, initCrc=0, xorOut=0, rev=True)`。

**Q7.★ half-cycle 标志处理**

实测流动站 GPS L1 每颗星恒定 half=1、BDS B3 每颗星恒定 half=1（接收机对整周模糊度附加了半周不确定性标志）。若按课件"标志异常即剔除"，这些频点全部被剔除 → 可用观测为零，程序无解。正确做法（本工程 `decode_rangeb_oem7()` 中的处理）：**解码时保留观测，对载波相位直接减 0.5 周**把半周偏置改正回整数周。方向改错（加 0.5 周）也无所谓：相位加 0.5 周等价于模糊度减 0.5 周，而整数最小二乘/LAMBDA 只会把 N 吸到 N±0.5 附近的整数上——模糊度参数本身 absorbs 这个常数偏置，结果不变。但注意真半周跳变（0.5 周跳）处理后已"整周化"，MW/GF 组合对整周跳敏感、对半周跳天然不敏感，因此**不能靠 MW/GF 探测**，要靠相邻历元 half 标志翻转来检测（本工程按此实现：发现标志翻转即把该星模糊度置为未初始化、重新收敛）。

**Q8.★ 同步阈值 0.5 s vs 课件 5~30 s**

基站/流动站数据各自从网络到达，时间标签靠周秒对齐（`main.cpp` 中 `SyncObsCommon()`，`SYNC_THRES_NET = 0.5`）。错位 4 s 配对意味着同一历元实际差 4 秒：卫星在轨约 3.9 km/s，4 秒内卫星位置变化十几公里，双差残差达公里级 → 模糊度永不收敛或固定到错误整数，RTK 彻底失败。课件取 5~30 s 是假设两端时钟粗对齐、只容忍传输抖动；本工程两路数据来自同一授时链，真实偏差远小于 0.5 s。更关键的是缺口场景：数据流断 2 s 恢复后，**5 s 阈值会把后续所有历元继续错位配对并"锁死"在错序上**（旧数据持续在窗口内），而 0.5 s 阈值宁可丢掉缺口两侧的历元，恢复后立即重新严格对齐——宁缺勿错。

## 第三档：双差模型与参数估计

**Q9.★ 符号约定推导与镜像解**

本工程 dP = P_base − P_rover。设 b = 流动站坐标 − 基站坐标，los 为基站指向卫星的单位向量。则 ρ_base − ρ_rover ≈ −los·b，于是双差观测 z ≈ −los·b，线性化后正确写法为：**A = +los，l = z + ρ0**（代码 `BuildDDModel()`）。若错取 A = −los、l = z − ρ0（全符号翻转），方程组仍是自洽的线性系统，最小二乘同样收敛、EKF 同样稳定，但收敛到 **−b 的镜像解**。不会发散是因为这不是随机误差而是模型性系统偏差：每历元观测都按同一错误符号进入，估计量在错误但一致的方程下是严格不动点。这正是最难发现的 bug 类型——数值上"稳定且漂亮"，物理上全错。

**Q10.★ LAMBDA 两步与 `FixPos = dPos + pos`**

LAMBDA：① Z 变换（整数高斯消元/逆 Cholesky 对模糊度协方差去相关），降低模糊度间相关性；② 在变换后空间做整数最小二乘搜索（本工程用改进的搜索/枚举）得固定模糊度 N_fix。ratio 检验：次优解残差平方和与最优解之比（定义视实现为 s₂/s₁ 或 1 − s₁/s₂），**阈值取 3.0**。固定后把 N_fix 代回方程，得到扣除固定模糊度贡献后的**位置改正数 pos**（相对浮点基线的增量），所以固定坐标必须是 `FixPos = dPos + pos`——dPos 是浮点基线、`pos` 只是修正量（`FixDDAmb()` 中实现）。若只输出 pos，等于把毫米级修正量当成坐标，结果落在参考位置（本工程即流动站 SPP 初值）附近，且当符号镜像时还会输出到错误的镜像点。

**Q11.★ 单侧 χ² 检验**

基线向量一致性检验：固定模糊度前后两基线的差 Δb 应服从 N(0, Σ)，统计量 var = ΔbᵀΣ⁻¹Δb ~ χ²(3)（课件限值 7.815 即 χ²₀.₉₅(3)）。本工程对单位权中误差一致性采用**单侧上界**（χ² 分布上分位数，实测 28 自由度时 χ²₀.₉₇₅(28)≈44，观测 var≈27~51）。原因：把模糊度固定到正确整数后，解的残差平方和**只会减小或不变**，统计量分布整体下移；若用双侧区间，下侧（如 χ²₀.₀₂₅）会把"确实收敛到正确整数"的解也判出去——即**系统性拒绝正确固定解**，表现为永远得不到固定解。单侧上界只拦"统计量大到离谱"的错误固定，符合该统计量的物理意义。

**Q12. EKF 与 LSQ 的模糊度参数化**

EKF（模式 1，`SolveKF()`）：模糊度作为滤波状态分量，过程噪声设为 0（视为时不变），跨历元递推其协方差——新观测逐步削减模糊度方差、且与位置状态的互相关被显式携带。LSQ（模式 2，`SolveFloat()`）：逐历元独立平差，模糊度作为历元内未知数，靠历元间几何变化（卫星升降、精度因子变化）逐步收紧。静态观测、1 Hz 采样、卫星几何变化缓慢时，**EKF 固定解来得快**：其信息积累不依赖几何变化，任何新观测都贡献信息；LSQ 在几何几乎不变时法方程病态，模糊度收敛慢甚至需等待星座变化。这也是配置中默认推荐 EKF 处理静态长时间观测的原因。

## 第四档：刁钻综合

**Q13.★ 零基线测不出镜像**

镜像 bug 解出的是 −b 而非 b。零基线天线同点，真值 b ≈ 0，其镜像 −b ≈ b ≈ 0——**镜像与真值重合**，7935 历元回归的"固定解 rms 毫米级"完全无法区分对错。启示：① 精度指标小 ≠ 正确，只能证明自洽；② 验证模型正确性必须用**非零且已知的基线真值**做差分对比（本工程实基线阶段以双天线已标定基线 dX=−469.568, dY=702.675, dZ=−1405.092 检验，立即暴露镜像）；③ 回归测试应包含"真值对比"而不只是"前后一致"。

**Q14.★ SPP 差 1.6 km 为何不毁 RTK**

RTK 的双差模型只约束流动站相对基站的基线向量 b：流动站绝对坐标仅作为**线性化参考点**出现在 ρ0 与 los 中。SPP 初值差 1.6 km 时，ρ0 的误差被常数项吸收，los 在小角度（1.6 km 对 2 万 km 轨道张角极小）下几乎不变，浮点解把参考点连同基线一起改正，一两轮迭代即收敛——绝对误差成为公共模式被彻底消去，与双差对钟差、轨道误差的消去机理同源。SPP 粗差会传导的情形：① SPP 输出本身被当作结果（SPP 模式）；② SPP 发散到无法提供有效初值（卫星数不足、粗差过大使线性化不收敛）；③ 用 SPP 坐标外推流动站动态先验时，突变会把滤波拉偏。基线向量本身不受影响。

**Q15.★ 绝对可观性来源与"基线对、坐标错"**

双差只约束 b，但 b 的定义两端不对称：**基站坐标是外部给定的已知值**（本工程从 BESTPOS 报文解码 `basPosFromStream` 锁存），浮点解给出 ΔX，流动站坐标 = 基站坐标 + ΔX。一旦模糊度固定、b 成为精确已知量，流动站绝对坐标就被"基站坐标 + 精确基线"唯一锚定——绝对可观性来自基站这个已知点，而非双差观测本身。若基站坐标用了旧残留值（错 δ），双差几何中 los 在短基线下于两处取值几乎相同，δ 产生的建模误差被模糊度和位置增量整体吸收，**基线估计不变，而流动站坐标 = 错基站 + 对基线**，整体平移 δ——"基线对、坐标错"。避免方法：基站坐标必须锁定后不再被覆盖（本工程在收到首个 BESTPOS 后锁存），且固定解应输出到由当前锁存基站坐标推算的框架内。
